# Playerinyo

Yerel müzik arşivleri için Electron tabanlı vibecoded masaüstü oynatıcı.

## Özellikler

- Yerel kütüphane, albüm görünümü ve çalma listeleri
- Çift ses kanallı geçişsiz oynatma ve crossfade
- Last.fm destekli Radio ve YouTube tabanlı uzaktan oynatma
- İndirme, metadata/kapak düzenleme ve şarkı sözleri
- Dinleme istatistikleri, beğeniler, yedekleme ve geri yükleme

## Başlatma

```bash
npm install
npm start
```

## Test

```bash
npm test
```

## Linux paketi

```bash
npm run package
npm run linux:install-desktop
```

Uygulama kodu `app/`, testler `test/`, belgeler `docs/` dizinindedir.
