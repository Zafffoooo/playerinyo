# Playerinyo

Yerel müzik arşivleri için Electron tabanlı masaüstü oynatıcı.

## Başlatma

```bash
npm install
npm start
```

## Test

```bash
npm test
```

## Linux paketi

```bash
npm run package
npm run linux:install-desktop
```

Uygulama kodu `app/`, testler `test/`, belgeler `docs/` dizinindedir.
